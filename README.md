# Theo Falkiner - Visual Artist Portfolio

A modern, colorful portfolio website built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

This site automatically deploys to GitHub Pages via GitHub Actions on every push to `main`.

**Live site:** https://ian-treleaven-outlook.github.io/theo-falkiner-portfolio/
